# 朋友局情感话题扩展设计

## 目标

在不改变题库总量和页面交互的前提下，为朋友局增加暗恋、心动、异性相处、理想型、暧昧关系和情侣互动等话题，使聚会抽题更有情感张力和可玩性。

## 题库数量

总题库继续保持 2000 道，其中朋友局 1500 道、情侣局 500 道。

朋友局的情感主题题目共 600 道，占朋友局的 40%，按难度和类型精确分配：

| 难度 | 真心话 | 大冒险 | 情感题合计 | 该难度占比 |
| --- | ---: | ---: | ---: | ---: |
| 轻松 | 75 | 75 | 150 | 30% |
| 进阶 | 100 | 100 | 200 | 40% |
| 刺激 | 125 | 125 | 250 | 50% |
| 合计 | 300 | 300 | 600 | 40% |

每个朋友局难度仍包含 250 道真心话和 250 道大冒险。情感题替换现有普通题，不增加总数。

## 内容梯度

### 轻松

- 理想型、喜欢的相处方式和容易心动的细节。
- 对异性朋友、暗恋和第一次心动的轻松回忆。
- 模拟约会邀请、夸奖、眼神交流和无压力的表达练习。

### 进阶

- 暗恋经历、暧昧信号、吃醋、错过的人和没有说出口的话。
- 对现场某人的好感判断、恋爱观和关系期待。
- 告白演练、真诚夸奖、选择心动对象完成自愿互动。

### 刺激

- 现场最心动的人、亲密偏好、暧昧经历和更直接的关系选择。
- 对视、牵手、拥抱、靠近、暧昧消息和模拟告白。
- 情侣在朋友局中可抽到更有张力的互动题，单身参与者也能通过假设、模拟或选择题完成。

## 安全与跳过规则

- 涉及另一位现场参与者的牵手、拥抱、靠近或其他身体互动，必须先获得对方明确同意。
- 涉及发送消息时，不发送露骨内容，不冒充他人，不联系明确不愿被打扰的人。
- 不包含强迫告白、强迫接触、偷拍、公开隐私、泄露密码、危险行为或露骨性行为。
- 任何参与者都可以拒绝或跳过题目，题目文案不以拒绝为惩罚。
- 默认参与者为成年人；文案保持暧昧和大胆，但不描写露骨性行为。

## 数据结构

- 为题目增加内部 `topic` 标记，取值为 `general` 或 `romance`。
- 朋友局六个题桶分别配置普通语料、情感语料和精确的情感题数量。
- 生成器分别构建普通候选和情感候选，再按目标数量合并，确保比例不受数组排序影响。
- 页面无需展示 `topic`，现有筛选、随机抽题和最近 50 题不重复逻辑保持不变。

## 验证

- 自动测试确认总题数仍为 2000，朋友局仍为 1500，情侣局仍为 500。
- 自动测试确认朋友局情感题总数为 600。
- 自动测试逐桶确认 75、75、100、100、125、125 的精确分布。
- 自动测试确认所有题目 ID 和可见文字唯一。
- 自动测试继续拦截强迫、偷拍、密码泄露、危险驾驶和露骨性行为。
- 新增检查确保涉及身体互动的情感大冒险包含“双方愿意”“征得同意”或等价的自愿措辞。
- 运行代码检查、完整测试、服务端构建和 GitHub Pages 静态构建。
