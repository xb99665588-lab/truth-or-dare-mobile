# 手机真心话大冒险设计

## 产品定位

这是一个独立的手机竖屏网页，专门供游戏输家快速抽取惩罚。它不管理玩家、轮次或积分，目标是三次点击内得到一条可执行的真心话或大冒险。

## 模式与题库

- 朋友模式：1500 道，占主要部分。
- 情侣模式：500 道。
- 总题库：2000 道，菜式般严格计数、稳定 ID、文本不重复。

朋友模式按轻松、进阶、刺激三个难度分配，每个难度的真心话和大冒险各 250 道。情侣模式的真心话和大冒险各 250 道，每种类型按轻松 83、进阶 83、刺激 84 分配。

情侣刺激内容允许较大胆的暧昧、亲吻、亲密表达和私密问答，但不得露骨描述性行为，不得包含强迫、羞辱、偷拍、危险动作或公开个人隐私。所有题目都可无条件跳过。

## 交互流程

1. 首页选择“朋友”或“情侣”。
2. 选择“轻松”“进阶”或“刺激”。
3. 点击“真心话”“大冒险”或“随机来一个”。
4. 卡片翻转并展示题目。
5. 用户可以点击“完成了”“换一个”或返回设置。

页面另提供转盘入口。转盘只决定真心话或大冒险，随后从当前模式和难度的对应题库抽题。抽取器记录最近 20 条题目并尽量避免重复，本地保存当前选择和完成数量。

## 视觉设计

只针对 360–430px 宽的手机竖屏优化。使用深紫黑背景、珊瑚红和电光紫作为主色，大标题与圆角卡片营造派对感。朋友模式偏蓝紫，情侣模式偏莓红。主要按钮置于拇指易触达区域，按钮最小高度 52px，支持安全区和减少动态效果偏好。

## 技术结构

- React 客户端组件管理模式、难度、抽取、转盘和本地记录。
- 题库生成器根据经过审核的中文语料片段和句式，在构建时确定性生成 2000 条题目。
- 独立领域函数负责筛选、随机抽取、最近题目去重和题库统计。
- 不需要登录、后端或远程数据库。

## 验证标准

- 总数严格为 2000；朋友 1500，情侣 500。
- 每个模式、难度、类型的数量符合约定。
- ID 与题目文本全部唯一。
- 页面可完成模式选择、难度选择、三种抽取、换题、完成和转盘流程。
- 生产构建成功，服务器渲染不再包含 starter 预览标记。
